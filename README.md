## usage
**commands** \
Commands can be ran on the selected project within the python code \
\
Claim a bot: `>bot claim code_here` (if you successfully claimed one you should get a reply from **tortesting** saying you own a bot) \
Set a bot's advertise target: `>bot target project_id` \
Set a bot's advertisement ID: `>bot advertise project_id` \
Run a bot: `>bot start` (you must have a claimed bot and target and advertise values set) \
Stop a bot `>bot stop`

## claim a bot without a code
If you want a bot but don't have a code go to this [class](https://scratch.mit.edu/classes/2109580/) \
Find the students and select one of their usernames \
Then go to this [website](https://www.base64encode.org/) \ 
Encode the username in base64 then copy the result \
Go back to the [command project](https://scratch.mit.edu/projects/1364330722/) and enter this comment with the code being the base64 result `>bot claim base64` \
example: \
`>bot claim SGVsbG9DYXQyMzAx`
